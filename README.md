# Clinic Management System

A C# Windows Forms application for managing patient records using SQL Server.

## Features
- Add new patient records
- Update existing patient information
- Delete patient records
- Search patients by name or phone number
- View patient records in a DataGridView
- Input validation for patient information
- SQL Server database integration

## Technologies Used
- C#
- Windows Forms
- SQL Server
- ADO.NET
- Visual Studio

## About the project
This project was developed to practice building a desktop application that connects a C# Windows Forms interface with a SQL Server database and performs basic CRUD operations.
